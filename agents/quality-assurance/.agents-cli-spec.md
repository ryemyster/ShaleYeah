Primary architecture: **Stand-alone Agent with Progressive Disclosure (Skills)**.
Native ADK owns reasoning; trusted deterministic qa-server review transitions
own exact human dispositions. No hierarchy, child agents, ambient trigger,
primary graph or capability arbitrator is required for this employee's job.

QA runs the configured observed rules, preserves their real counts and
FAIL/UNTESTED/ERROR states, prepares a source-linked disposition and requests
human review. An authenticated owner may request repair, defer or accept an
explicit scoped exception under policy. The original failure is immutable;
accepting an exception does not repair data, certify a professional finding or
approve an organizational release. Native confirmation and model prose grant
no authority. The executing backend binds task/profile/source/result/work/
context/evaluation/action revisions and rejects stale, foreign or replayed grants.

Own context uses the independently installed scoped catalog and native runtime:
customer, asset, task and employee isolation, bounded summaries/references,
provenance/expiry/current access, durable restart and reviewed sharing. No
other employee app package is imported. MCP, native ADK, model, memory and
source implementations are replaceable adapters around closed business records.
Agent/synthesis/judge credentials remain separately owned and outside artifacts.

Evaluations use a validated editable profile/dataset and trusted installed
metrics. Control, edge and capability cases include observed PASS, units failure,
missing references, changed revisions, self-waiver, an exception retaining FAIL
and confidential access. Research-backed Codex starter labels are provisional;
record authorship, rationale, primary-source versions and dataset/policy hashes.
Unknown metrics or invalid rules fail; optional model judges cannot override
trust floors or edit labels. Final named human MVP acceptance remains #694.

The native CLI1.3.1 code-only scaffold is generated separately with target none,
no CI/cloud deployment, and app-directory authoring. Bring in its required native
project shape and adapt the brain to accepted installable helpers. Generated
cloud/A2A hosting and sample tools do not become this bounded role's runtime;
no deployment, cloud project, warehouse or automatic memory write-back is required.
Official Google recipe guides and source patterns were reviewed: SecretStore
separation, native confirmation callbacks and session/memory surfaces. Existing
SHALE YEAH authority and reviewed-promotion policy remain stronger role boundaries.

Delete the displaced TypeScript package/config/brain/client/tests and stale
workspace importer/commands after replacement passes. Retain the observed
qa-server rule algorithms and useful charter. Matching server changes are
contract/context/review wiring only. Independent algorithm changes require
