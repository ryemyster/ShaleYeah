# Reporter implementation specification

Owning issue: #541. The implementation plan is recorded before code in issue
comment6135107986. This is one employee migration; shared state/provider/review
helpers move as first-order dependencies, with Geologist regression evidence.

Primary architecture: **Stand-alone Agent with Progressive Disclosure (Skills)**.
The native ADK brain selects bounded role tools. Deterministic review transitions
live in the executing backend. No child agents, ambient trigger, hierarchy,
graph-as-primary or capability arbitration is required for report assembly.

The employee reads exact permitted reviewed upstream work, prepares a private
source-linked report and requests human review. The owner can request changes,
reject or approve the exact qualified revision. Approval prose, confidence,
native confirmation and a task title grant no authority. Private release stores
only that snapshot; no external send, investment choice or reserve/legal
certification is implemented. Unknown and conflicting evidence stays visible.

Inputs: canonical task/work/context/review contracts, exact authenticated origin
and recipient sharing receipts, configured audience/purpose/template/disclosures.
The business-artifact interface is explicit JSON and is not the LAS/CSV raw-data
connector profile. Local owner-only exports are operator attestations; remote
hosts inject authenticated authority services through the source interface.

Shared helpers are installable libraries. Reporter does not import another
employee or backend implementation. ADK is an optional native runtime adapter;
contracts, model profiles, MCP services and authority/state adapters remain
replaceable. Models and secrets belong to agent/synthesis/judge independently.
No model names, deployment target or default credentials grant working access.

Evaluation: tests/eval/performance_profile.json selects installed metric IDs,
versions, thresholds and dataset hashes; tests/eval/datasets/reporter.json defines
control, edge and capability cases. Trust floors cannot be removed or softened.
Frozen counterexamples and native offline provider journeys are fixture evidence,
not measured professional accuracy. Codex research review supplies initial
expectations, with editable rubric/configuration and contributor refinement.
Final named human MVP and professional acceptance remain separate plan gates.

Deleted in this migration: package.json, tsconfig.json, biome.json, the custom
TypeScript loop, private MCP client, TypeScript agent tests and fabricated server
summary/network-sentinel tests. Root workspace importer and obsolete tool hints
are removed. No temporary Reporter runtime adapter remains.

Extraction acceptance requires clean declared-dependency source/wheel installs,
independent compatible MCP peers, protected review/context restart, configured
providers, role qualification, metadata-only events and secret/access negative
controls. Source shape or tests alone do not satisfy that evidence.
