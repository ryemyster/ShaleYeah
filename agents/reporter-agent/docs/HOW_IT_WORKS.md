# How Reporter works

The owner supplies the audience, purpose, template, disclosures and permitted
reviewed specialist work. Reporter reads current source revisions and drafts a
private report. Each source contributes its stated values, units, assumptions,
uncertainty and missing findings. Conflicting values remain visible.

The owner reviews the draft and may request changes. A revised draft needs a new
exact review packet. The separate executing service checks source rights,
qualification and the human's decision before storing the approved private
publication revision. Restart recovery and retries use that same packet.
