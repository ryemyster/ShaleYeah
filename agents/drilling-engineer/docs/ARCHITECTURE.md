# Drilling Engineer architecture

The employee uses **Stand-alone Agent with Progressive Disclosure (Skills)**: one ADK specialist loads bounded original evidence as needed. `create_drilling_engineer_agent` uses the installed ConfiguredModel, provider/event controls and typed independent MCP tools. The backend supplies canonical arithmetic and non-waivable exceptions; the employee contributes cited observations and questions.

`DrillingEngineerRuntime` wraps the installed EmployeeRuntime and scoped ContextCatalog. Successful tool calls retain exact permitted metadata. Before review, the adapter redrafts and compares current canonical work, then obtains host-owned context and stores only the pending review reference. Credentials and human grants are excluded from model context. Raw output cannot promote itself to shared knowledge.

The separate shared review supervisor resumes a qualified exact human-approved private-record transition. Native tool confirmation is an additional interaction, not reviewer authority. Source revision, scope, rights or enrollment changes invalidate stale continuation. Optional orchestration and any hosting target remain separate.
