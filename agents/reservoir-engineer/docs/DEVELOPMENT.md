# Development

From this package, run `uv sync --locked`, then `uv run --locked ruff check app tests`
and `uv run --locked pytest -q --cov=app --cov-fail-under=90`. `uv build --wheel`
builds the independent employee artifact. `agents-cli info` reads scaffold
metadata; model configuration remains explicit and host-owned.

Write failing code/contract controls before implementation. Grade actual native
output and tool usage through configured evaluations rather than asserting that
a live model produces particular prose in unit tests. Keep numerical references
independent of Curve-smith's production solver.

Changes to source mapping, models/providers, runtime, context, review or evaluation
configuration require affected package and protected journey checks. Run the
Curve-smith extraction and container controls for packaging or shared boundary
changes. See [evaluations](EVALUATIONS.md) and the [delivery contract](../../../docs/sdlc.md).
