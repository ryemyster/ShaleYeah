# Local testing

The Python suite exercises the native factory, tool mappings, strict final-output
parsing, current-source context, restart and an independent external MCP peer.
The frozen evaluation runner exercises control, edge and capability-boundary
cases against independently known synthetic rate histories.

For the complete pair, build Curve-smith and run its package tests. The native
HTTP journey uses real ADK, provider SDK adapters, the installed MCP client,
context catalog, evaluation runner and backend review store. Only model responses
are offline fixtures. A separate human CLI inspects the packet; installed
qualification is required before approval and private save. Restart, replay and
revocation remain part of the journey.

These tests need no paid model credentials. They establish fixture execution and
control behavior, not live model competence, field accuracy or professional
acceptance. Initial inputs and labels remain available for domain review and
contributor correction.
