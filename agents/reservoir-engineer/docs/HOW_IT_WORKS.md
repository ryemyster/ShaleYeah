# Forecast workflow

1. Read the assigned task and current permitted history, well/completion identity,
   operating basis and forecast assumptions. Inspect coverage metadata first;
   retrieve exact source pages when detail is needed.
2. Reconcile product, daily-rate units, time conversion, source grain and dates.
   Unsupported period totals, shut-ins, missing or conflicting inputs defer the
   work rather than being interpolated or silently excluded.
3. Compare declared fixed-b Arps alternatives. Fit only training observations;
   keep later observations for validation. Preserve actual counts, residuals,
   unavailable values and failed configured standards.
4. Return canonical source-linked `work` and `forecast`. Finite modeled cohort
   volume is an equal-well mean; future-only quantities are per well. Neither
   becomes observed cumulative production or certified reserves.
5. Prepare exact private review. A separately enrolled human inspects sources,
   assumptions, context, output and evaluation, then requests changes, rejects or
   approves that revision. Changed evidence requires fresh work and review.
6. Resume only the current qualified approved private save. Durable state makes
   repeated continuation idempotent; current source rights still apply.

The human owns operating judgment and consequential decisions. The employee
does not certify reserves, operate field controls, commit capital or publish work.
