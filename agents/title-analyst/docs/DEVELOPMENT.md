# Develop Title Analyst

Follow the repository's sequential SDLC from an open issue and a branch based on develop. Write failing behavior/evaluation controls before implementation, keep one role's output scoped, update affected docs/changelogs and delete displaced paths before review.

Keep role instructions, typed arguments, source fixtures and human decisions here. Reuse installed model, MCP, context, event, evaluation and review helpers. Protocol handling and a second reasoning/review state machine do not belong in this package. Tests must exercise actual output and authority failures, not merely inspect source text.

Freeze independent expected behavior before changing the implementation or grader. Preserve source citations, authorship, hashes, previous labels/results and provisional status when a reviewed revision is necessary. Actual captured backend output is a test observation, never replacement expected truth. Run the package, backend, shared evaluation and CI-policy checks affected by a change. See [evaluation](EVALUATIONS.md).
