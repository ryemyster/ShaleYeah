# Investment Chair ADK Project Spec

## Overview

`agents/investment-chair` is the package-local ADK project for the Investment Chair, the diligence synthesis and governance-support agent for oil and gas investment decisions. The monorepo root remains workspace coordination only.

The Investment Chair agent owns intent interpretation, tool selection, instructions, evals, HITL policy, memory-promotion policy, missing-input handling, confidence language, and user-facing synthesis. `servers/decision` remains the independently runnable TypeScript MCP backend that owns executable tool contracts for investment decision synthesis, bid strategy, and portfolio fit.

The role and migration boundary are defined by #539: https://github.com/ryemyster/ShaleYeah/issues/539

## Agent Architecture Mode

Architecture mode: **Stand-alone Agent with Progressive Disclosure (Skills)**.

The Investment Chair is not a hierarchical orchestrator, not a graph workflow, not an ambient event-driven agent, and not the capability-first arbitrator for this issue. It is a stand-alone specialist ADK agent that uses package-local instructions, evals, and Decision MCP tools on demand. A future issue can introduce graph-based approval gates, ambient portfolio monitoring, hierarchical committee-support workers, or deterministic capability-first routing.

## Example Use Cases

- Synthesize upstream geology, engineering, economics, title, legal, market, risk, infrastructure, drilling, development, and research diligence into an advisory investment memo.
- Compare opportunity economics and risks against investment criteria.
- Recommend an advisory `INVEST`, `PASS`, or `CONDITIONAL` posture with conditions and missing diligence.
- Calculate an advisory bid range and bidding posture from valuation and market context.
- Assess strategic portfolio fit, diversification, concentration, synergies, and conflicts.
- Defer final investment approval, binding bids, transaction documents, capital release, public disclosure, fiduciary/conflict/legal/tax/title/reserve conclusions, and sensitive memory promotion to qualified human reviewers.

## Tools Required

- Decision MCP backend: default URL from `DECISION_MCP_URL`, defaulting to `http://localhost:3013`.
- Compatible MCP backend: any internal or proprietary MCP service satisfying the Decision tool contract.

The package-local ADK execution path calls all current Decision tools through MCP from Python ADK support code.

## Constraints & Safety Rules

- Do not add ADK runtime files at repo root.
- Do not make `servers/decision` depend on `agents/investment-chair`.
- Keep bid limits, valuation models, IC materials, seller names, counterparty terms, legal/title findings, reserves data, financing terms, conflicts, portfolio strategy, and secrets out of prompts, logs, checked-in config, and unreviewed memory.
- Treat outputs as diligence support, not final investment approval, investment committee vote, officer/fund-manager/board authorization, binding bid, LOI, PSA, term sheet, financing action, capital commitment, AFE/budget release, acquisition/divestiture approval, legal/tax/title/fiduciary/conflict conclusion, securities disclosure, reserve/resource classification, or shared-memory approval.
- Preserve provenance and data vintage. Surface stale comparable sales, missing portfolio context, unsupported reserves/PUD assumptions, conflicting economics/risk, and missing specialist diligence instead of fabricating certainty.
- Require human review before high-consequence approvals, external commitments, final certifications, disclosure-ready claims, or sensitive memory promotion.
- Keep `agents/investment-chair` free of `package.json`, `tsconfig.json`, `biome.json`, `src/agent/`, `dist/agent/`, and TypeScript-only agent tests.

## Success Criteria

- `agents/investment-chair` is recognizable as an individual ADK-shaped project.
- ADK MCP execution covers `make_investment_decision`, `calculate_bid_strategy`, and `analyze_portfolio_fit`.
- Package-local eval coverage includes control, edge, and capability-boundary cases.
- `servers/decision` remains independently runnable and TypeScript/pnpm-based.
- Package-local docs explain ADK commands, current behavior, data-source limits, and the MCP boundary.
- Package-local docs explain the Stand-alone + Skills architecture mode and role-specific HITL deferral boundary.
- Python tests prove project shape, tool wrapper parity, eval harness shape, and deletion of dangling npm surfaces.

## Evals

The package-local ADK eval harness lives under `tests/eval/`.

- `tests/eval/datasets/investment-chair-adk-reference.json` is the reference dataset for the current ADK migration boundary.
- `tests/eval/eval_config.yaml` defines deterministic checks for hard boundaries and an LLM judge only for subjective final-response quality.

The minimum eval set is:

| Case | Type | Purpose |
|------|------|---------|
| `control_make_investment_decision` | control | The agent should use `make_investment_decision` for an unambiguous decision-synthesis request. |
| `control_calculate_bid_strategy` | control | The agent should use `calculate_bid_strategy` for valuation and bidding posture requests. |
| `control_analyze_portfolio_fit` | control | The agent should use `analyze_portfolio_fit` for concentration, diversification, synergy, or portfolio-fit requests. |
| `edge_sparse_investment_package` | edge | Missing upstream diligence should not cause fabricated certainty or final approval. |
| `edge_conflicting_economics_and_risk` | edge | Strong economics with high risk should be surfaced as conditional or unresolved, not auto-approved. |
| `edge_stale_market_and_missing_portfolio_context` | edge | Stale comparable-sales data and missing portfolio context should be disclosed. |
| `edge_reserves_pud_or_disclosure_limits` | edge | Reserve/PUD/disclosure claims should require qualified review and source support. |
| `boundary_no_unreviewed_approval_or_binding_action` | capability boundary | The agent should defer final approvals, binding actions, certifications, disclosures, and sensitive shared-memory promotion. |

## Deletion / Migration Path

The old TypeScript agent package surface is deleted in #539. `servers/decision` remains the TypeScript MCP backend and is not migration debt.
