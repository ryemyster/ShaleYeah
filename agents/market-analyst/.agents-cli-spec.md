# Market Analyst employee adoption spec — #684

## Scope and selected mode

One role adoption, one branch and PR into develop.
Primary mode: **Stand-alone Agent with Progressive Disclosure (Skills)**.
ADK owns one native tool reasoning
loop. Shared employee components provide context, provider configuration, events,
scorecards and review supervision; the separate Market MCP backend owns domain
calculation and executing authority. No child-agent hierarchy, graph-agent runtime,
ambient scheduler or capability arbitrator is introduced. Backend business-state
transitions do not change the agent's primary mode.

## Inputs and outputs

The assigned task binds exact mandate, dated series and commercial-assumption JSON
sources. Preserve commodity, region, period/frequency, as-of, publication vintage,
retrieval time, source URI, native/target units and applicable heat content.
The employee proposes interpretation and references; source arithmetic stays in
the backend. Final output is exactly work/market or an explicit deferral. Missing,
stale, foreign-region or unconvertible required data cannot qualify as complete.

## Authority, memory and runtime

An enrolled separate human inspects exact source bytes, assumptions, work, context,
evaluations and private-record action. Installed qualification precedes approval
and execution. Changes invalidate stale review; restart/replay cannot record twice.
No trading, contract, bid or capital authority is supplied. Model confirmation
cannot supply approval. Context is private, scoped, currently authorized and
retained by explicit policy; raw model text cannot promote itself to memory.

Use the installed MCP 2026-07-28 client and shared configured Gemini/Anthropic
adapters. Pin deployed provider/model revisions; isolate judge credentials.
The backend's optional advisory synthesis uses the same configured-provider
contract and owner check, without implicit legacy model/environment fallback.
No deployment target, paid data provider, orchestrator or vector store is required.

## Evidence and acceptance

Freeze research-backed provisional initial labels before implementation. Keep
old config/reference bytes and results. The 21-case scorecard includes controls,
edges and capability boundaries, with twelve protected source/quality/trust gates.
Grade actual final text separately from host source/dispatch observations.
Human operating authority and final named MVP acceptance remain separate.

Required verification covers native ADK and actual MCP under both offline provider
transports, private source/context/review/restart and input revocation, installed
qualification, a compatible external service, independent source/npm archive/
Python wheels and separate non-root containers. CI must reject missing, failed or
skipped selected Market qualification and retain exact-revision metadata.
A local bind restriction or absent Docker is unverified acceptance, not a pass.

## Deletion and retained behavior

Retain useful market-condition and competitor queries, evidence/freshness behavior
and optional advisory interpretation. Retain role instructions and native ADK
shape. Replace package-private global wrappers with installed-client methods;
replace inline eval YAML, keyword/shape-only tests and its old reference dataset
with actual contract tests, declarative scorecard, native trace grading and
installed verification. Delete displaced copies in this PR. The TypeScript agent
surface was removed earlier; this package must keep no npm/tsconfig/src-agent
runtime. Shared legacy runtime deletion remains #692 after its last consumer.

## Limits

Operator data rights and commercial suitability are operator-attested. All initial
fixture values are fictional and labels are provisional. No paid connector,
professional certification, measured accuracy or production deployment is claimed.
Complete #684 only after package, native, independent artifact/container and exact
PR/merge checks pass. The next issue is #685 after SDLC completion.
