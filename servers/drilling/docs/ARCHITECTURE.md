# Drilling MCP architecture

Drilling is an independent deterministic MCP backend. The packet module validates three explicit exports and computes exact depth, quoted-cost and schedule arithmetic. The source service validates current scope/rights, bytes, revisions, freshness and content before each result. Normalized snapshot hooks use installed connectors; model-generated engineering defaults are absent.

The installed shared EmployeeReviewWorkflow owns durable review transitions. The role adapter rebuilds source facts and compares exact work/packet/context before approval or execution. The separate enrolled reviewer and installed qualification must remain current; native confirmation and model output cannot grant authority. Private idempotent recording grants no operational or capital approval.

The public compiled entry owns its dependency graph and exposes no work tools without source configuration. SDK, contracts and connectors are declared dependencies. Audit uses required redacted structured events; credentials and human grants are excluded from prompts and retained employee knowledge. See the [input](INPUTS.md) and [integration](INTEGRATION.md) contracts.
