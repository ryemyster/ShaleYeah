# Check supplied drilling options

The backend loads exact design, corpus and constraint exports under current task/source/actor authority. It checks dates and well/design/formation identity, explicit MD/TVD/datums and section coverage, required quoted lines and sequential phases, hazards and offset applicability. It preserves supplied component references without validating mechanical engineering sufficiency.

The employee supplies original-evidence-cited observations and questions. The backend validates byte identity and required coverage, returns canonical unreviewed work, and carries unresolved exceptions as blockers. It computes no field controls, mud weights, default rates, drilling speeds or risk probabilities.

A separate enrolled engineer inspects the exact source/work/context/evaluation revision. Changes or rejection cannot authorize an earlier revision. Current exact qualification and approval permit one private record; restart/retry returns the same receipt. Source or reviewer revocation blocks continuation.
