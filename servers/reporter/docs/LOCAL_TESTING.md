# Testing Reporter tools

Run `pnpm test` in this directory. The controls exercise literal assembly, zero
and absent values, IRR scales, conflicting findings, required disclosures, current
review/sharing receipts, private configuration, human edits, exact approval,
restart and replay. Security controls deny employee self-approval, stale/revoked
rights, fabricated publication prose and caller-selected output paths.

State-machine unit tests use an explicitly trusted qualification verifier double.
They test durable transitions, not professional accuracy or installed qualification.
The employee scorecard separately uses the installed portable evaluator with
versioned source/authority counterexamples. Initial research review defines these
fixture expectations; real operator truth, live model quality and review effort
remain separately measured outcomes.
