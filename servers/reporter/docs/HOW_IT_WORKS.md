# How the Reporter service works

The owner configures the task, audience, template and disclosures. The service
reads only permitted reviewed source snapshots, then creates a source-indexed
report. Measured values remain measured, assumptions remain assumptions, and
missing or conflicting information stays visible. Geological confidence cannot
become a net-pay measurement, and IRR retains its declared units.

The human reviews the exact publication packet. Changes require a new draft.
The executing service checks qualification and current rights before the exact
approved snapshot enters private reviewed reports. The same snapshot survives
restart and repeated requests return the stored result. External sending and
professional certification are outside this bounded service.
