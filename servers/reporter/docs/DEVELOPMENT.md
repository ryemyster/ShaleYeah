# Developing Reporter tools

Follow the sequential issue-to-develop workflow. Write failing source fidelity,
authority and restart cases before changing behavior. Keep useful literal report
assembly and remove unsupported defaults. Domain investment algorithms belong to
their owning specialist; Reporter presents source conclusions.

Use package-local TypeScript build/lint/test commands. Shared review, private-file
or qualification changes also require the Geowiz reference controls. Actor identity,
source rights, audit and redaction belong to the executing code, with prompt
instructions serving only as guidance. Model notes remain unreviewed.
