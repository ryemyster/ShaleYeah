# Production calculation and review

The numerical tools require explicit product, daily-rate units, fixed time basis,
finite horizon, economic cutoff, exact references and model assumptions. For
analog histories, each well is fitted separately with the declared fixed b.
Unusable cohorts stay unavailable; identifier counts cannot create a type curve,
confidence, P10/P50/P90 distribution or a reservoir interpretation.

The employee service additionally requires three current authorized JSON sources:
history, operating basis and forecast assumptions. It rejects inconsistent grain,
completion identity, dates, units and unsupported period/shut-in interpretations.
Only observations through the fitting cutoff train the model. Later observations
supply actual validation diagnostics; configured minimum counts and error
thresholds determine quality. Failed standards block the work for review.

Modeled volume is finite and starts at declared time zero; the cohort quantity
is an equal-well mean. Remaining volume is separate for each well from its last
observation to the modeled stop. A model integral never becomes observed
production or certified reserves. Optional unreviewed synthesis of numerical-tool
results cannot change values or grant approval.

Drafting preserves exact sources/assumptions and unavailable uncertainty. Separate
human review binds the exact input, work, context, evaluation and action revisions.
The backend independently rederives them and requires current installed
qualification before private save. Restart/replay cannot duplicate a save;
changed/revoked sources invalidate continuation. See [inputs](EMPLOYEE_INPUTS.md).
