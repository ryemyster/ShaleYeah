# Integrating Curve-smith

Use an MCP client with the selected 2026-07-28 profile over stdio or configured
protected HTTP. The TypeScript package exports `CurveSmithServer`,
`ProductionForecastService`, `ProductionForecastWorkflow` and
`createProductionSnapshotHook` with declared options. A host can inject its own
trusted current source/identity authority without importing the employee.

The private-file binding reads exact operator exports using the installed SDK
verified file reader. The normalized snapshot hook accepts only its explicit
JSON profile, current grants and verified bytes/metadata; it does not certify a
vendor-native format, live API or data redistribution right. Credentials are
resolved by the host after authorization and are excluded from returned content.
See [input and review configuration](EMPLOYEE_INPUTS.md).

The employee-facing tool API can retrieve, calculate, compare, draft and prepare
review. Separate authenticated human inspection/decision is in
`examples/review.mjs`. Host policies, installed qualification and exact business
approval remain required even when a client or model claims success.

A compatible external employee can call this server directly. An alternative
backend can implement the same selected role surface. Provider credentials,
external employees, data hooks and coordinators have separate conformance needs;
one successful substitution does not certify the others.
